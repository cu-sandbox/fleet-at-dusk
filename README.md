# Fleet at Dusk

A single-player, Battleship-style naval guessing game. Open `index.html` in any modern browser to play. No installation or server is required.

Place each ship on Your Waters by selecting its first square. Ships extend right or down depending on the rotation setting. You can also choose **Randomize fleet**. After you start the battle, choose a square in Hostile Waters. The computer returns fire after each shot. The first side to sink the other fleet wins.

Use Tab to reach a board, the arrow keys to move between squares, and Enter or Space to select one.
